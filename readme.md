# Centre d'adoption canine

Mon premier site responsive : la page d'un centre d'adoption qui présente ses chiens (Fido, Bella, Max), adaptée aux écrans d'ordinateur, de tablette et de mobile.

## Stack

HTML · CSS

## Ce que j'ai travaillé

- Mise en page qui s'adapte à la largeur de l'écran (media query à 768 px)
- Images au format AVIF, plus légères que le JPEG

## Lancer le projet

Aucune installation : ouvrir `index.html` dans un navigateur.
